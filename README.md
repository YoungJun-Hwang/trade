# TradePilot — 무역 실무 도우미

품목을 입력하면 **HS코드 → 품목별 절차 → 국가별 인증 → 법규 체크 → 바이어 발굴 → 비용 계산 → 서류 생성 → 통관·물류·결제 관리**까지 이어지는 웹 프로그램입니다.
빌드 없이 `index.html`을 열면 바로 동작하며, GitHub Pages로 배포할 수 있습니다.

## 실행

```bash
# 그냥 index.html을 더블클릭하거나, 로컬 서버로 실행
python3 -m http.server 8080   # → http://localhost:8080
```

```bash
npm test   # 계산 엔진 테스트 (Node 18+)
```

## 외부 API 연동

브라우저에서 관세청·수출입은행 API를 직접 호출하면 CORS 차단과 인증키 노출 문제가 있어 **프록시**를 둡니다.

1. `proxy/cloudflare-worker.js`를 Cloudflare Workers에 배포
2. 인증키를 비밀변수로 등록: `UNIPASS_CARGO_KEY`, `UNIPASS_EXPORT_KEY`, `EXIM_KEY` (선택: `ALLOWED_ORIGIN`)
3. 앱의 **설정 → API 프록시 URL**에 배포 주소 입력

| 연동 | 프록시 없을 때 | 프록시 있을 때 |
|---|---|---|
| 환율 | open.er-api.com 공개 시세(실패 시 예시 환율) | 한국수출입은행 매매기준율 |
| UNI-PASS 화물통관 진행 / 수출이행 | 데모 데이터 | 관세청 실데이터 |
| 화물 위치 추적 | 선사 추적 페이지 링크 | 설정한 추적 엔드포인트 JSON(`{vessel, position, eta, events}`) |


## 주의

- 관세율·인증·운임은 **참고용 기본 데이터**입니다. HS 세번은 10단위 HSK로 관세법령정보포털에서, 인증은 인증기관·KOTRA에서, 운임은 포워더 견적으로 최종 확인하세요.
- 법규 체크 결과는 확인 항목 안내이며 법률 자문이 아닙니다.
- 입력한 품목·거래·설정은 사용 중인 브라우저(localStorage)에만 저장됩니다. 설정 → 전체 백업으로 내보낼 수 있습니다.
